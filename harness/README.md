# tstack harness tree

This folder is generated from `tstack/skills`, `tstack/agents`, `tstack/docs/guide`, `tstack/docs/harness/claude-code.md`, `tstack/README.md`, `tstack/LICENSE`, and `tstack/plugin.json`. Do not edit it by hand.

Cursor uses `tstack/` directly, and Claude Code installs `claude-code/`. The tree leaves out the rest of `tstack/`, such as `tstack/assets`. A relative link to a tstack file that the tree leaves out points at that file on GitHub `main` instead.

After editing those sources, run `python3 scripts/generate-tstack-harness.py` from the repository root and commit the result.
